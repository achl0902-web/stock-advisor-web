# 시세 차트 소스 복구 및 빌드

2026-11-27: `assets/sise.js`의 재현 가능한 **소스 프로젝트를 복구**했습니다.

## 출처와 복구 범위

- 2026-11-12 최초 시세판 추가 커밋부터 이미 압축된 번들만 저장되어 있었습니다.
- 당시 작성자가 작업한 **원래 JSX/TSX 파일 자체는 Git 기록·브랜치·소스맵에 남지 않았습니다.**
- 대신 2026-11-27 배포본에서 시세판 전용 로직을 분리·정리하고 공개된 React 및 [Funnest Charts](https://github.com/funnest-xyz/funnest-charts) 모듈과 다시 연결했습니다.
- 결과물은 **원본과 동일한 파일 복구가 아니라 기능 기반 재구성**입니다. 현재 시세판 UI, 데이터 공급자, GitHub 통신을 소스 상태에서 다시 빌드할 수 있습니다.

| 파일 | 역할 |
| --- | --- |
| `src/board-datafeed.js` | 시장 데이터·시간봉 캐시·페이지네이션·주문/체결 표시 |
| `src/github-board.js` | GitHub board-data 읽기, 3초 폴링, 수집 완료 판정 |
| `src/chart-app.jsx` | React 시세판 UI, 차트, 관심종목, 가격선, 히트맵 |
| `scripts/build-chart.mjs` | 소스→`assets/sise.js` 정적 배포 번들 생성 |
| `package-lock.json` | 설치 라이브러리 및 빌드 도구 버전 고정 |

사용 버전: React/ReactDOM **19.2.0**, Funnest Charts UI/React **0.6.31**, esbuild **0.25.12**.
Funnest Charts는 Apache-2.0, React는 MIT 라이선스이며 기존 차트 표시·출처 표기를 유지합니다.

## 개발

```sh
npm ci
npm run build:chart
npm run check
```

- **`assets/sise.js`를 직접 수정하지 마세요.** 변경은 `src/`에 적용하고 재빌드합니다.
- GitHub Actions는 `npm ci`로 설치하고 테스트 이후 생성된 배포 번들이 Git에 저장된 결과와 같은지 검사합니다.
- 테스트는 60분봉 파일 폴백, 과거 구간 탐색, KRX 호가 단위, 장전·장후 시세, 수집 완료와 이력 커밋 구분, 실제 번들의 초기 화면 실행을 포함합니다.
- `index.html`은 별도 서버가 필요 없는 GitHub Pages 정적 페이지이며, 토큰은 기존과 동일하게 브라우저 로컬 저장소에서만 읽습니다.

## 검증 한계와 이후 작업

1. 복구 당시 사용한 Funnest Charts의 **정확한 버전은 번들에 명시되지 않아** 공개 API가 호환되는 0.6.31로 고정했습니다. 차트 렌더링은 추가적인 실기기 비교가 필요합니다.
2. iPhone Safari에서 60분/일/주/월 전환, 좌우 이동·핀치 확대, 내 체결 ▲▼, 4개 팔레트, 터치 영역을 최종 확인해야 합니다.
3. 화면 로직은 읽을 수 있게 포맷·모듈화했지만 일부 지역 변수는 번들에서 복원한 축약 이름을 유지합니다. 변경하는 컴포넌트부터 단계적으로 의미 있는 이름과 JSX로 정리할 수 있습니다.

이 파일은 라이브러리의 제3자 원본 코드를 복사해 유지하는 방식이 아니라, 공개 npm 버전을 잠가 재빌드하는 구성입니다.
