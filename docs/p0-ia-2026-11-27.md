# P0 화면 구조 재설계 — 2026-11-27

## 변경 이유

기존에는 `홈`이 시세판이면서 QLD 전략·관심가·일정을 포함했고, `기록`에 과거 판단과 미래의 주문·관심가·ETF가 함께 있었습니다. 사용자가 가격을 확인하거나 오늘 필요한 행동을 점검하려면 여러 화면을 이동해야 했습니다.

## 변경 전후

| 화면 | 이전 | 이번 변경 |
| --- | --- | --- |
| 첫 진입 | 시세판이 첫 화면 | **오늘**: 시세 상태·운용 계좌·관심가·주문·전략·최근 판단·시장 일정 |
| 하단 탭 | 홈 · 자산 · 기록 | **오늘 · 자산 · 시장 · 기록** |
| 자산 | 운용 계좌 묶음 + DC·코인 분리 | **단일 자산 화면**에서 네 계좌를 선택해 같이 보거나 제외. 기본 주 계좌+바이오. 기존 도넛·성과만 유지하고 별도 상세 메뉴와 중복 차트 제거 |
| 시장 | 차트 앞에 전략·관심가·시장 일정 | 차트 중심. 관심가 전체·ETF를 시장 아래로 이동 |
| 기록 | 최근 판단·주문·일정·성과 + 과거 판단 | 과거 판단과 성적에 집중 |

## 사용자 검증 후 구성 간소화

- 사용자가 원본 미리보기에서 지적한 중복 **계좌별·선택 합계·수익률 3모드 비교 차트 및 추가 도넛**을 제거.
- 계좌 토글이 기존 계좌 구성 도넛, 선택 합계, 입출금 반영 성과·수익률·평가액 추이와 보유 내역에 직접 적용된다. 기존 계좌 선택 목록·도넛을 누르면 해당 계좌 상세를 같은 화면에서 확인한다.
- 별도 DC 상세·코인 상세 메뉴 제거. 이전 상세 주소는 `#/assets`로 보낸다.
- 선택 계좌가 하나 이상 유지되도록 하고, 기본값은 메인+바이오(가족 보기에서는 메인+코인). 토큰으로 데이터 접근 자체를 제한하지는 않음.
- 오늘 현재가 표시와 원/$ 환산은 기존 `worthSeries`·`inUsd`를 재사용하고, 별도 차트용 데이터 계산·렌더러 코드를 삭제.

## 검증 및 병합 조건

- `npm run check`와 계좌 토글→기존 도넛·성과 갱신, 마지막 계좌 유지, 가족 보기 기본값에 대한 DOM 회귀 테스트.
- iPhone Safari 320/375/390px: 오늘 첫 화면, 통합 추이의 계좌 선택, 하단 탭 겹침, 도넛 선명도, 긴 텍스트, 날짜 선택 QA.
- `?view=family` 공유 화면: 바이오·DC·판단 정보가 노출되지 않는지, 신규 기기에서 로그인 토큰을 요구하는지 확인.
- 사용자 확인 후 병합. 기존 자료의 신뢰도와 값 계산 원칙은 그대로 유지.
