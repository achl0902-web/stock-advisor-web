# P3 시장 모바일 UX — 2026-11-27

## 문제

- 기존 모바일 화면은 **시장 지수 띠 → 차트 → 관심종목** 순서이므로 관심종목을 바꾸려면 차트 아래까지 내려갔다가 다시 올라와야 했다.
- 캔버스 안쪽의 좁은 확대/좌우 이동 단추는 손가락으로 정확히 조작하기 불편했다. 긴 과거 구간으로 이동하는 방법이 잘 드러나지 않았다.
- 차트 하단/관심가 연결/모바일 기간 칩 일부는 44px 터치 목표에 못 미쳤다.
- 큰 OHLC 범례가 모바일 차트 면적을 차지했다.

## 변경과 이유

1. **차트 바로 위에 관심종목 빠른 전환.** 현재 시세판의 `watch` 데이터에 있는 종목만 가로 스크롤 가능한 44px 높이 버튼으로 표시한다. 선택 시 `aria-pressed`와 색상으로 표시하고, 이미 존재하는 `setSymbol`/데이터 캐시를 그대로 사용한다. 별도 종목 가격·성과 카드는 추가하지 않는다.
2. **캔버스 내장 소형 내비게이션 대신 외부 조작 영역.** 모바일에서는 Funnest Charts의 `navigationButtons`를 끄고 차트 바로 아래 `과거·다음·축소·확대·최근` 다섯 버튼을 둔다. 각각 44px 이상. `scrollBars`, `zoom`, `scrollToRealtime`, `timeScale.visibleRange`는 복구한 Funnest Charts의 공개 API다. 축 이동 시 이미 있는 과거 구간 요청·캐시 경로를 사용하며 가격 데이터나 계산을 변경하지 않는다.
3. **가로축 한계 완화.** 화면이 좁아도 최신 300봉에 고정될 필요 없이 `과거` 버튼으로 표시 폭의 약 60%씩 이동하면서 더 오래된 기록을 탐색할 수 있다. `축소`로 넓게, `확대`로 자세히 보고 `최근`으로 현재 위치에 돌아온다. 최대 과거 길이는 데이터 공급자의 실제 저장 기록에 좌우된다.
4. **차트 정보 밀도 조정.** 모바일 `legendValues: "crosshair"`로 차트의 모든 OHLC 정보를 항상 점유하지 않고 선택 시에만 보여 준다. 데스크톱은 기존 표시를 유지한다.
5. **터치·선택 접근성.** 모바일 기간 칩, 시장 안쪽 탭, 관심가 연결, 관심종목 행의 터치 높이를 44px 이상으로 조정한다. 외부 차트 버튼에는 동작이 명시된 `aria-label`을 제공한다. 좁은 화면에서는 5열 버튼이 그리드 안에서 줄어들며 가로 스크롤을 만들지 않는다.

## 유지·검증

- Funnest 원본 라이브러리 버전, 분/일/주/월 전환, 드로잉과 평단·관심가, 데이터 수집 시점, 기존 온디맨드 시간봉·캔들 캐시는 변경하지 않았다.
- 모바일 가상 데이터 DOM 회귀에서 빠른 종목 버튼 2개, 차트 외부 버튼 5개, 버튼 조작, 종목 전환 후 `aria-pressed` 상태를 검사한다.
- `npm run check`: 시세판 원본 소스로 재빌드 → 구문 검사 → 테스트 → 저장된 배포 번들 일치 검증(GitHub CI).
- 정적 320/375/390px 규칙·44px 버튼 크기를 확인한다. **iPhone Safari 실기기 확대·스와이프·VoiceOver 사용성은 배포 후 사용자 검증이 필요하다.**
