# 시세 정확성·조회 속도 UX 개선 (2026-11-28)

## 원인과 수정

1. **최근 수집 ≠ 최근 가격**: 종가 날짜가 오래됐어도 자산 화면은 과거값을 현재 평가액으로 계산했다. 이제 백엔드의 `required_quotes`, `stale_quotes`, `errors`를 개별 종목에 연결해 검증된 시세만 현재 평가에 쓴다. KIS 복구 종가는 출처를 표시한다. 환율 검증 실패 시 달러 자산의 원화 평가도 보류한다.
2. **입금이 순익으로 표시될 위험**: 현재 평가액이 자산 이력보다 먼저 바뀌면 차액 전부가 투자손익에 들어갔다. 현재 보유 수량·원화 및 달러 현금과 마지막 이력의 장부 구성이 같을 때만 현재 평가액을 그래프에 추가한다. 다르면 마지막 기록까지 보여 주면서 이유를 안내한다.
3. **거대한 차트 초기 로딩**: 10년 이상 일봉 전체 파일을 첫 화면에서 다운로드했다. 최근 600봉 파일을 우선 사용하고, 과거로 탐색하면 원본 전체 파일을 캐시해 이어 붙인다. 서버 파일 미배포 시 이전 파일 방식으로 자동 호환된다.
4. **불필요한 자동 수집**: 매번 화면을 열 때 3분 전 스냅숏이면 새 Actions를 시작하던 정책을 장 중 10분, 코인 1시간으로 조정했다. 휴장 중 일반 주식은 수동 갱신을 제공한다.

## 유지한 UX

- 계좌 토글 기본값(주 계좌+바이오), 기간 슬라이더 기본 열림, `±7일` 날짜 조정, 선택 계좌 성과·도넛 차트, 모바일 내비게이션은 유지.
- 데이터 검증이 실패했을 때 현재 평가·수익률은 보류하고 기존 자산 이력 기준일을 표시한다. 이전 종가는 `지연 종가`로 구별해 보여 준다.

## 배포 순서·테스트

1. 백엔드와 수집 워크플로를 먼저 배포한다. 새 `required_quotes`와 `barsrecent` 파일은 다음 수집부터 생성된다.
2. 웹 차트 소스와 재생성된 배포 번들을 병합한다. 기존 데이터 포맷에 대한 폴백을 테스트한다.
3. CI의 단위·차트 렌더·모바일 브라우저 테스트 및 Actions 건강 상태를 확인한다.

주의: 초기 부하와 통신량은 파일 크기로 정적 비교했으며 실제 사용자의 iPhone Safari 네트워크/VoiceOver 성능은 기기에서 추가 확인해야 한다.
