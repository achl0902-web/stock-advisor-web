# P1 자산 UX 개선 — 2026-11-27

## 사용자 의견

- 기간 시작·종료 손잡이를 움직이면서 투자손익·기간 수익률·자산 추이가 변화하는 경험을 선호한다.
- 이전 구현에서는 기본 `1년` 프리셋 때문에 슬라이더가 접혀 있었고, 기간 버튼을 다시 누르면 또 닫혔다.
- 수익률 추이를 가장 자주 확인한다. 계좌 선택은 상단 토글 하나로 충분하므로 아래의 중복 **선택 계좌 구성** 카드·도넛·계좌 선택 목록은 필요하지 않다. 단, 선택 계좌의 **보유종목 구성 도넛**은 유지한다.

## 반영

1. **슬라이더 기본 펼침.** 빠른 기간 버튼을 누르더라도 유지. 직접 손잡이를 움직이면 날짜·선택 프리셋·성과 그래프를 동일 이벤트 흐름으로 갱신한다. 스크롤 중 상단으로 따라오는 슬라이더도 유지한다.
2. **컨트롤 높이 축소.** 슬라이더는 보이되 날짜 직접 입력과 ±7일 미세 조정은 별도의 펼침 옵션으로 이동한다. 사용자가 원하면 세밀하게 조정할 수 있다.
3. **자산 정보 우선순위 변경.** 계좌 토글 → 기간 조절 → 선택 계좌의 성과/수익률·평가액 추이 → 보유종목 구성 도넛·보유목록 순서로 배치. 별도 계좌 구성 카드와 그 카드에 종속된 선택 목록은 삭제한다. PC에서는 추이 영역이 한 칸을 모두 사용한다.
4. **상세 정보의 단계적 표시.** 기초·기말 금액, 순 입출금, 투자원금은 기본 표시. 실현손익·배당·평가손익 분해는 펼쳐서 본다. 계산식과 값은 변경하지 않았다.
5. **모바일 가독성.** 계좌 토글 선택 상태를 색·체크 표시로 이중 표현하고, 390px 이하에서는 성과 수치와 헤더를 유연하게 줄바꿈한다. 기존 보유종목 도넛과 텍스트 보유목록은 유지한다.
6. **계좌 조작 중복 제거.** 상단 토글만으로 여러 계좌를 합치거나 한 계좌의 상세 데이터를 조회한다. 한 계좌만 켜면 그 계좌 이름·목표·위험자산 한도까지 보여 준다. 하단 계좌 도넛 조각을 누르는 별도 경로는 제거하여, 조작 대상과 정보용 차트를 구분한다.
7. **모바일 접근성.** 토글의 `aria-pressed`와 키보드 포커스 표시를 유지하고, 기간 상세 열기·7일 이동·목표 설명 펼치기·공유 보기 링크를 최소 높이 44px의 터치 영역으로 맞췄다. 320px에서는 날짜 입력과 미세 조정을 한 열로, 375/390px에서는 날짜 입력 두 열·계좌 토글 두 열로 배치한다. 하단 고정 메뉴의 iOS 안전 영역 여백도 유지한다.

## 검증 범위

- 기본 슬라이더 펼침, 프리셋 버튼 클릭 이후 펼침 유지, 손잡이 입력 후 기간과 수익률 화면 갱신
- 계좌 토글(전체 합계↔단일 계좌), 가족 보기, 원/$ 표시·날짜 직접 선택과 보유종목 도넛 회귀 확인
- 중복 `data-comp` 카드·계좌 선택기 부재 검증, 320/375/390px 반응형 CSS·44px 조작 영역·하단 안전 영역 회귀 검증
- `npm run check` (차트 빌드·구문 검사·DOM 회귀 포함)
- CSS·DOM 회귀 검사는 자동화했으며 iPhone Safari 실기기에서의 터치 편의성·보이스오버 탐색은 별도 확인 대상이다.
