# P5 통합 UX 개선 — 2026-11-27

## 목적과 기존 화면 존중

- 자산 추이를 조작하는 즐거움을 중심 경험으로 유지한다. 기본 선택은 주 계좌·바이오이며, DC·코인을 같은 토글로 더하고 뺀다.
- 중복 합계 위젯, 별도 계좌 상세, 가로 비중 막대, 추가 비교 그래프는 도입하지 않는다. 기존 보유종목 도넛은 유지한다.
- 오늘 → 자산 → 시장 → 기록 정보 구조와 네 가지 색 테마를 유지한다.

| 공통 | 자산 이력 커밋과 시세 수집 시간을 구분하는 새로고침·갱신 안내 | 동기화 성공을 최신 시세로 오인하는 상황 감소 |
| 공유 | 가족 보기와 개인용 토큰의 권한이 분리되지 않았다는 경고를 설정·화면에 표시 | UI에서 숨기는 것과 실제 접근 제한을 구별 |

## 검증

- `npm run check`는 React 시세판 소스 빌드, JavaScript 문법 검사, Node DOM·계산 회귀 테스트를 실행한다.
- 기간 범위·계좌 토글·도넛·기록 검색과 계좌 미선택 방지를 점검한다.
- 터치 대상은 44px 이상을 우선하며, 320·375·390px에서 줄바꿈·컨테이너 최소폭을 점검한다.
- 본 자동 검사는 iOS Safari 실기기 테스트를 대신하지 않는다. 특히 실제 iOS 브라우저의 하단 주소 표시줄, 안전 영역, 소프트 키보드와 조작 충돌은 사용자 기기에서 추가 확인이 필요하다.

## 남은 설계 결정

**독립된 공유 URL의 비공개 데이터 접근 제어는 이번 UI 변경 범위에 포함되지 않는다.** 기존 `?view=family`는 화면에서 계좌를 숨기는 모드이므로 개인 토큰 전달이 안전하지 않다. 안전한 제3자 공유를 만들 때는 공개할 계좌·금액 범위, 갱신 주기, 별도 데이터 저장소/API 및 토큰 발급·만료 정책을 먼저 결정해야 한다.
