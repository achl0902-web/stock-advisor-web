# 모바일 가독성·테마 일관성 감사 및 개선 기록 (2026-11-27)

## 범위

stock-advisor-web의 판단 일지·자산·시세판 모바일 UI를 새 기준으로 검토했다. 코발트 옐로를 대표 팔레트로 유지하되, 블랙 라임·에스프레소 민트·스톰 오렌지까지 동일한 대비·터치·반응형 기준을 적용한다. 재무 계산식과 API 호출 방식은 바꾸지 않았다.

## 정량 규칙 및 자동 검증

- 네 테마 모두 강조 경계색 대 패널 및 높인 카드의 대비 **3:1 이상** (비텍스트 경계 기준).
- 네 테마 모두 가장 약한 보조 글자색 대 패널 대비 **4.5:1 이상** (일반 텍스트 기준).
- 자동 회귀 테스트에서 테마 선택기와 토큰의 브랜드색 일치, 완료 기록 불투명 유지, 기간 직접 선택 열기/접기, 시세/차트 색상 변수 사용 및 모바일 줄바꿈을 확인한다.
- 변경된 프리셋/날짜 입력은 기존 normalizeDateRange, 슬라이더, 차트 갱신 경로를 그대로 사용한다.

## 남은 수동 QA

이 문서는 정적 검증과 CI 범위를 기록한다. iOS Safari 실기기 검증으로 다음을 최종 확인하는 것이 좋다.

1. iPhone 폭 320, 375, 390px에서 계좌·연금·코인 및 시세판 가로 스크롤이 생기지 않는지.
2. ‘기간 직접 조정’ 펼침, 날짜 팝업, 두 슬라이더 손잡이, 프리셋 재선택, 스크롤 시 뜨는 막대의 표시 상태.
3. 네 테마 각각에서 색약 환경과 햇빛 아래 경고, 보조 글자, 입력 경계의 식별 가능성.
4. 테마를 바꾼 직후 시세판 스파크라인·히트맵·캔버스 차트가 동일한 상승/하락 색상 체계를 사용하는지.

실기기 검증 이전에 그 결과를 ‘통과’로 표기하지 않는다.
